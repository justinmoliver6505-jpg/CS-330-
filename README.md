# CS-330- Final disposition
**How do I approach designing software?**
This project helped me become more comfortable breaking large problems into smaller, manageable tasks. Instead of trying to build everything at once, I focused on one feature at a time, tested it, and then moved on to the next improvement. I learned the importance of planning ahead and thinking about how different parts of a program interact before writing code.
For this project, I built a working foundation first and then expanded it through each milestone. I used classes, vectors, and organized logic to keep the program easier to maintain and improve. These design skills will be useful in future projects because they help create cleaner and more organized solutions.

**How do I approach developing programs?**
The biggest strategy I used was iteration. I frequently tested, debugged, and refined my code as new features were added. Each milestone built on previous work, allowing me to improve the project over time.
My approach evolved throughout the course. Early on, my focus was simply getting the program to run. By the end, I paid more attention to organization, readability, and how changes affected the overall program. Features such as collision detection, brick health, and physics effects helped strengthen my problem-solving and debugging skills.

**How can computer science help me in reaching my goals?**
This course improved my understanding of computational graphics, object-oriented programming, and problem solving. These skills will support my future studies in computer science and data analytics while helping me approach complex problems more effectively.
Professionally, the project reinforced the value of analyzing problems, developing solutions, and continuously improving a process. These are skills I can apply both in software development and in leadership roles throughout my career.
